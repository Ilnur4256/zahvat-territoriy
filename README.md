# Захват территорий

Гео-игра: весь мир разделён на шестиугольники (система H3, ~0,1 км² каждый). Две фракции захватывают их, находясь рядом физически, по GPS. Изменения видны всем игрокам в реальном времени.

## Что уже работает
- Карта всего мира (OpenStreetMap) с сеткой гексов, тёмная тема, адаптив под телефон, планшет и ПК; можно установить на экран телефона (PWA).
- Регистрация: позывной + выбор фракции (Фракция 1 / Фракция 2) — навсегда.
- Кланы: создать (название + тег) или вступить в клан своей фракции; можно играть без клана.
- Захват только в своём гексе и соседних (~350 м вокруг игрока). Сервер сам проверяет GPS: точность, свежесть, «телепорты» быстрее 300 км/ч блокируют захват на минуту.
- Боевая система: у гекса прочность 1–5. Захват/атака стоит 1 энергию (20 макс., +1 каждые 30 с). Свой гекс можно укрепить за 5 монет.
- Экономика: каждый гекс приносит владельцу 6 монет в час, +20% сверху идёт в казну клана. За захват +2 монеты.
- Онлайн через WebSocket: захват перекрашивает гекс у всех, кто смотрит на этот район; владелец получает уведомление «ваш гекс атакуют».
- Рейтинг фракций, топ кланов и игроков.

## Запуск у себя
Нужен Node.js 18+.
```
npm install
npm run dev        # http://localhost:3000, тестовый режим
```
В тестовом режиме (`DEV=1`) появляется жёлтая кнопка-метка: включите её и нажимайте на карту, чтобы «переместиться» без реального GPS. На боевом сервере `DEV` не включайте.

## Как выложить в интернет (чтобы играть с телефона)
Геолокация в браузере работает только по HTTPS, поэтому нужен хостинг с HTTPS.

**Render.com (бесплатно, проще всего):** загрузите папку в репозиторий GitHub → на render.com «New → Blueprint» → выберите репозиторий (файл `render.yaml` уже есть). Через пару минут получите ссылку вида `https://zahvat-territoriy.onrender.com`.
Ограничение бесплатного тарифа: сервер засыпает без игроков и при перезапуске теряет данные (файл `data/state.json`). Для теста с друзьями нормально, для запуска — нет.

**VPS (Timeweb Cloud, Selectel, Yandex Cloud и т. п.):** есть `Dockerfile`.
```
docker build -t zahvat .
docker run -d -p 3000:3000 -v zahvat-data:/data --restart=always zahvat
```
Перед ним поставьте Caddy или nginx с сертификатом Let's Encrypt.

## Настройки
Все игровые числа — в начале `server.js`, объект `CFG`: размер гекса (`RES`), радиус захвата (`CAPTURE_RING`), энергия, доход, цена укрепления.

## Устройство
- `server.js` — HTTP + WebSocket сервер, вся логика и проверки на сервере (клиенту не доверяем).
- `public/` — клиент: Leaflet (карта) + h3-js (гексы), без фреймворков.
- Данные хранятся в `data/state.json` (сохранение каждые 10 с).
- Клиент подписывается только на регионы, которые видит на экране, — сервер шлёт обновления только туда.

## Что дальше (по приоритету)
1. База данных PostgreSQL + PostGIS вместо JSON-файла, Redis для онлайна — чтобы держать тысячи игроков.
2. Вход по телефону/Telegram вместо токена в браузере (сейчас аккаунт привязан к браузеру).
3. Защита от подмены GPS: проверка на стороне нативного приложения (mock location на Android), анализ траекторий.
4. Нативная обёртка (Capacitor) для App Store / Google Play и пуш-уведомлений «ваш гекс атакуют».
5. Трата монет: магазин (щиты, ускорители энергии), клановые постройки, ежедневные задания «посети новый район».
6. Ценность территорий: достопримечательности и центры районов дают больше дохода — стимул ездить.
7. Тайлы карты: при росте аудитории перейти на свой тайловый сервер или платный (MapTiler), правила OSM не позволяют большую нагрузку.
